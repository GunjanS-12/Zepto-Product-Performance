# Zepto-Product-Performance
# Project Overview:

This project is an end-to-end Business Intelligence solution built to analyze product pricing, discount strategy, and inventory performance for Zepto.

The objective was to transform raw product-level data into meaningful business insights using SQL for data preparation and Power BI for interactive visualization.

# Tools & Technologies:

MySQL – Data cleaning and analysis

Microsoft Power BI – Dashboard development

DAX – Measures and calculated columns

SQL – Aggregation and business logic implementation

# Dataset Description:

The dataset contains product-level information including:

SKU ID

Category

Product Name

MRP

Discount %

Discounted Selling Price

Available Quantity

Product Weight (grams)

Stock Status

Quantity Sold

# Project Workflow:
1️⃣ Data Preparation (SQL)

Created database and structured product table

Removed invalid pricing records (MRP = 0)

Converted price from paise to rupees

Checked for null values and duplicates

Performed exploratory queries for insights

2️⃣ Data Modeling (Power BI)

Connected MySQL to Power BI

Created calculated columns and DAX measures

Built revenue, discount, and inventory metrics

3️⃣ Dashboard Development

Designed purple-themed interactive dashboard

Added KPI cards for key metrics

Built category-level revenue analysis

Created stock distribution visualization

Added interactive slicers for filtering


# Key Insights:

Identified high-revenue product categories

Evaluated pricing efficiency using price-per-gram metric

Analyzed stock availability across categories

Assessed impact of discount strategy on revenue

# Project Outcome:

This project demonstrates strong skills in SQL data transformation, DAX calculations, and dashboard storytelling.

It represents a complete BI workflow:
SQL (Data Cleaning) → Power BI (Modeling & Visualization) → Interactive Business Insights
